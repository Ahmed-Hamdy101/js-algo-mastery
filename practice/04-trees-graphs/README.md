# Trees and Graph Practice

Train on tree structures and traversal patterns here.

## Focus
- Binary trees
- AVL trees
- Rotations
- Traversal logic
- Graph ideas and patterns

## Exercise format

- Draw the structure.
- Write the traversal by hand.
- Implement the code from memory.
- Explain the balance and complexity.

## Technical questions

- What is the difference between a tree and a graph?
- How does an AVL tree maintain balance?
- Why do rotations matter?
- What is the difference between DFS and BFS?
- How do traversal patterns change the time complexity?

## Example files

- binary-tree.js — tree construction and inorder traversal
- dfs.js — depth-first search example
- bfs.js — breadth-first search example

## Interview prompts

- Walk through a tree traversal step by step.
- Explain why balancing is important.
- Why might a binary search tree become unbalanced?
- Can you solve a tree problem without looking at notes?

## Self-check

Before moving on, you should be able to:
- explain the structure clearly
- trace traversal logic by hand
- describe balancing and rotation logic
- write the code from memory
