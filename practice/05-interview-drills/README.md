# Interview Drills

This is the final practice layer before the challenge and interview work.

## Focus
- Explain algorithms out loud
- Solve under time pressure
- Write clean code
- Discuss trade-offs and edge cases

## Daily drill

- Solve 1 problem without notes
- Explain the approach in plain English
- State time complexity
- Review mistakes
- Repeat

## Technical questions

- What is the core idea behind the solution?
- What are the main trade-offs?
- What are your edge cases and failure modes?
- Which data structure best fits this problem?
- How would you optimize it further?

## Example files

- solve-one.js — interview-style problem solving example
- explain.js — explain-and-validate approach with palindrome logic

## Interview prompts

- Explain your reasoning out loud.
- Walk through the algorithm in a clear sequence.
- Describe the complexity and why it matters.
- Prove that your solution handles the edge cases.

## Self-check

Before moving to challenges or interviews, you should be able to:
- solve a problem without notes
- explain your reasoning clearly
- state complexity confidently
- identify and fix mistakes without help
