# Data Structures Practice

Focus on structures and their trade-offs.

## Focus
- Sets
- Maps
- Stacks
- Queues
- ArrayList
- LinkedList

## Exercise format

- Implement from memory.
- Test edge cases.
- Write Big O for operations.
- Explain when to use each structure.

## Technical questions

- When would you use a Set instead of an Array?
- Why are Maps useful for key-value lookups?
- What is the difference between stack and queue behavior?
- What is the cost of insertions and deletions in a linked list?
- How do ArrayList and LinkedList differ in access patterns?

## Example files

- set.js — Set usage and uniqueness
- map.js — key-value storage with Map
- stack.js — LIFO stack behavior
- queue.js — FIFO queue behavior
- linked-list.js — singly linked list example

## Interview prompts

- Explain the strengths and weaknesses of each data structure.
- Which structure would you choose for a given problem?
- What are the edge cases for insertion, deletion, and lookup?
- Can you write each structure and explain its complexity?

## Self-check

Before moving on, you should be able to:
- code each structure from memory
- explain when to use it
- state time complexity for common operations
- discuss trade-offs clearly
