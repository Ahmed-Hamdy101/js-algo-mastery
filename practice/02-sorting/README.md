# Sorting Practice

Practice sorting logic and complexity here.

## Focus
- Insertion sort
- Merge sort
- Quick sort
- Bubble sort
- Median and selection logic

## Exercise format

- Implement each sort from memory.
- Compare runtime behavior.
- Explain best/average/worst case.
- Solve a custom array variation.

## Technical questions

- Which sorting algorithm is best for nearly sorted data?
- How does merge sort differ from quick sort?
- Why is bubble sort usually not used in production?
- What is the time complexity of each algorithm?
- When would you choose insertion sort over quick sort?

## Example files

- insertion-sort.js — sort by moving items into place
- merge-sort.js — divide and conquer merge sort
- bubble-sort.js — classic O(n^2) sort
- quick-sort.js — pivot-based recursive sort

## Interview prompts

- Explain how the algorithm works step by step.
- Compare two sorting methods and justify the trade-offs.
- What edge cases should you test?
- Can you write the algorithm without looking at notes?

## Self-check

Before moving on, you should be able to:
- implement each sort from memory
- explain the complexity clearly
- describe when each one is useful
- identify the worst-case behavior
