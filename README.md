# JavaScript Data Structures & Algorithms Study Lab

A polished, hands-on repository for learning data structures, algorithms, interview prep, and production-minded problem solving in JavaScript.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6%2B-ffd43b?logo=javascript&logoColor=black)
![Node.js](https://img.shields.io/badge/Node.js-18%2B-339933?logo=node.js&logoColor=white)
![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

## Why this repo stands out

- Structured chapter-based learning path from fundamentals to interviews
- Real-world coding challenges modeled after common engineering scenarios
- Focus on time complexity, problem decomposition, and implementation quality
- Beginner-friendly examples with senior-level interview preparation material

## Quick start

```bash
git clone <your-repo-url>
cd _javascript_solving_problem
node COMPREHENSIVE_QUIZ.js
```

## Project goals

This repository helps developers:

- understand core data structures and algorithms
- practice with interactive JS exercises
- prepare for technical interviews and system design discussions
- build intuition for complexity and trade-offs

## Recommended learning path

1. Study each chapter from `chapters/chap-01-fundamentals/` through `chapters/chap-12-rotations/`
2. Practice the concepts in the dedicated `practice/` folder
3. Run the comprehensive quiz and identify weak areas
4. Solve the challenge set in `challenges/`
5. Move into advanced interview practice under `interview-prep/`
6. Revisit complex topics until they feel natural

## Core sections

### Fundamentals

- `chapters/chap-01-fundamentals/` – Big O, recursion, searching, Fibonacci, bubble sort
- `chapters/chap-02-sorting/` – insertion sort, merge sort, median and tests
- `chapters/chap-03-divide-conquer/` – quick sort and notes
- `chapters/chap-04-sets/` – sets
- `chapters/chap-05-maps/` – maps
- `chapters/chap-06-stacks/` – stacks
- `chapters/chap-07-queues/` – queues
- `chapters/chap-08-array-list/` – ArrayList
- `chapters/chap-09-linked-list/` – LinkedList
- `chapters/chap-10-trees/` – tree structures and depth exploration
- `chapters/chap-11-avl/` – AVL trees and balancing concepts
- `chapters/chap-12-rotations/` – tree rotation examples

### Practice tracks

- `practice/` – dedicated skill-building area after finishing chapter study
- `challenges/` – real-world coding challenge set
- `interview-prep/` – advanced algorithms, graph problems, web performance, and quiz material

## Run examples

```bash
# run the quiz
node COMPREHENSIVE_QUIZ.js

# run a chapter example
node chapters/chap-01-fundamentals/01-big-o.js
node chapters/chap-03-divide-conquer/01-quick-sort.js
node chapters/chap-07-queues/queue.js
```
