## What this repo is

This repository is designed to help developers:

- learn core data structures and algorithms
- study chapter-by-chapter in a structured way
- practice interview-style coding problems
- understand time complexity and trade-offs
- solve real-world engineering problems in JavaScript

## Recommended flow

1. Start with fundamentals
2. Move through each chapter in order
3. Practice in the practice folder
4. Solve challenge files
5. Use interview-prep resources for deeper review

## Chapter overview

### Fundamentals

- chap-01-fundamentals: big O, recursion, searching, Fibonacci
- chap-02-sorting: insertion sort, merge sort, median, bubble sort
- chap-03-divide-conquer: quick sort and divide-and-conquer patterns
- chap-04-sets: unique collections and set operations
- chap-05-maps: key-value storage

### Data structures

- chap-06-stacks: LIFO behavior
- chap-07-queues: FIFO behavior
- chap-08-array-list: dynamic arrays and list operations
- chap-09-linked-list: nodes and pointer-based structures
- chap-10-trees: tree concepts and traversal
- chap-11-avl: balanced BSTs and rotations
- chap-12-hash-table: hashing, indexing, and lookup
- chap-13-functional-programming: map, filter, reduce, and functional patterns

## Quick start

```bash
git clone <your-repo-url>
cd problem-solving-javascript
npm install
npm run quiz
```

## Run examples

```bash
# run the main quiz
node COMPREHENSIVE_QUIZ.js

# run a chapter file
node chapters/chap-01-fundamentals/01-big-o.js
node chapters/chap-03-divide-conquer/01-quick-sort.js
node chapters/chap-12-hash-table/hash-table.js
```

## Practice workflow

```text
Learn concept -> read chapter notes -> run JS examples -> solve practice tasks -> do challenge -> review complexity
```

## Goals of this repo

This project is meant to be a learning sandbox, not just a code dump.

It focuses on:

- understanding how structures work
- understanding why they are used
- seeing trade-offs in complexity
- preparing for technical interviews
- building good coding instincts

## Useful folders

- challenges/: coding interview-style problems
- chapters/: structured explanations and implementations
- practice/: smaller exercises and drills
- interview-prep/: advanced prep materials and quizzes
- COMPLETE_GUIDE.md: broader study guide
