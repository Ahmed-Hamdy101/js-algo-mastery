## 💡 Pro Tips

### For Learning:
1. **Don't just read** - Type out the code
2. **Break it** - Modify and see what happens
3. **Teach it** - Explain to someone (or rubber duck)
4. **Use it** - Build something real with the pattern

### For Practice:
1. **Time yourself** - Real pressure helps
2. **No solutions** - Resist the urge to peek
3. **Think out loud** - Practice for interviews
4. **Multiple approaches** - There's never just one way

### For Interviews:
1. **Clarify first** - Ask questions before coding
2. **Start simple** - Brute force, then optimize
3. **Test often** - Don't wait until the end
4. **Discuss trade-offs** - Show you understand implications
5. **Stay calm** - Deep breath, think, then speak

## 📞 Quick Help

**Stuck?**
- Check CHEAT_SHEET.md for patterns
- Review HOW_TO_USE.md for details
- Re-read problem hints carefully
- Take a break and come back

**Confused about complexity?**
- O(1) - Constant, like hash map lookup
- O(log n) - Logarithmic, like binary search
- O(n) - Linear, like array scan
- O(n log n) - Like merge sort
- O(n²) - Nested loops

**Not sure which data structure?**
- Need fast lookup? → Hash Map
- Need order? → Array or LinkedList
- Need LIFO? → Stack
- Need FIFO? → Queue
- Need prefix search? → Trie
- Need min/max? → Heap
